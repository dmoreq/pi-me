# Web Research

Use `web_search` to discover sources, then `web_fetch` to read the target page.

## When to use
- Current or changing information
- Documentation lookup
- Verifying a claim from a source page
- Finding official references before acting

## Rules
- Prefer primary sources.
- Search first, fetch second.
- Don’t rely on mock or placeholder web code as live web access.
- Summarize the source, not the search snippet.
